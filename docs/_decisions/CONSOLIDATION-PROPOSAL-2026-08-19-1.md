# Consolidation Proposal 2026-08-19-1

Skill-prompt changes proposed by the second `consolidate-learnings` pass, over seven LEARNINGS:
`pdlc-review-loop-hardening` (2026-07-30), `pdlc-merge-phase` (2026-08-02), `pdlc-advisory-tier`
(2026-08-05), `pdlc-consolidation-agent` (2026-08-11), `pdlc-headless-engine` (2026-08-12),
`pdlc-engine-distribution` (2026-08-16), `pdlc-plugin-retirement` (2026-08-18).

**Nothing here has been applied.** Agents proposing changes to the prompts that govern agents pass
through human judgment. Review each row and apply or reject it.

**`CONSOLIDATION-PROPOSAL-2026-07-29.md` rows P-1 … P-11 remain unapplied.** This pass does not
re-propose them. P-1 (hand the REQ stopping rule to reviewers at dispatch) still has the largest
measured cost behind it and is *corroborated again* here: `pdlc-consolidation-agent` burned two
five-round Phase R windows and `pdlc-plugin-retirement` fifteen REQ rounds, neither on contested
user need.

**Read Q-1 through Q-3 first.** They carry the largest measured cost in this corpus: a hollow wave
gate cost ~40 dispatches on one feature, and four PLAN tasks in another were unrunnable at HEAD.
