| F-01 | Medium | Cross-Feature | **A tenth site the sweep cannot see, because the sweep is directory-restricted: `pdlc/README.md:231`.** The sweep's warrant is its scope — `pdlc/engine/__tests__/ pdlc/workflows/__tests__/` — and inside that scope it is now sound. Widening the same grep to the repo (`grep -rln "escalation-view" --exclude-dir=node_modules --exclude-dir=docs .`) returns those four plus one more that transcribes a member list: `pdlc/README.md:231` — *"The four workflow modules it dispatches (`orchestrate-dev.js`, `orchestrate-queue.js`, `lib/loop-session.mjs`, `lib/escalation-view.mjs`) are vendored into the package at pack time"*. Under option A, `lib/stats.mjs` joins `MODULE_NAMES` and is vendored, so that sentence's count and its list both go stale on this feature's commit. Nothing reds — I checked: `documentOracles.test.js` reads `pdlc/README.md` at `:316`, `:672` but pins `workflows/dist/` (D-3, `:357`) and the absence of seam-count prose (`:625`), never the member list — which is why this is Medium, not High. | F-02 | Medium | Cross-Feature | **The command the document cites returns fourteen, not fifteen, and gives no sign it dropped one.** The count is right; the instrument is not. `grep -rln "escalation-view" pdlc/engine/__tests__/ pdlc/workflows/__tests__/` — the command quoted verbatim as the sweep — returns **14** files on a standard toolchain, silently omitting `pdlc/workflows/__tests__/loopProperties.test.js`. Cause: that file contains two literal NUL bytes at `loopProperties.test.js:370` (`` `${n.code}\0${n.subject}\0${n.text}` ``, a deliberate field separator), so grep classifies it as binary and skips it. `git grep -l` reads it and returns 15, which is where the document's figure comes from. Here the dropped file is a mere importer, so the nine-site set is unaffected and the arithmetic survives — but the failure mode is silent and would have been identical had the dropped file been a *transcriber*, which is precisely the class of miss this revision exists to end. That matters more than usual because K-9 promotes this instrument to `docs/_constraints/DOMAIN-CONSTRAINTS.md` as a project-wide rule (*"derive that set with a query"*), where the next feature will run it against a different tree. **Fix:** cite `git grep -l …` (or `grep -ral …`) in both the document and the promoted constraint text, and state that the two forms disagree on files containing NUL bytes — one clause that makes the rule reproducible for whoever inherits it. | REQ O-2, REQ C-5 |
