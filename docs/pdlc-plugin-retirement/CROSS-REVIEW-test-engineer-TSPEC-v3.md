| F-01 | High | Local | **TT-3's new set-equality companion contradicts the enumeration it is written against — as specified it can only fail.** Half (b) enumerates `{ cleanup-consumer-workflows.sh, check-scope-field.sh, guard-harvest-before-delete.sh, nudge-consolidation.sh }` and then requires that enumeration to **set-equal the executable scripts actually tracked under `pdlc/hooks/scripts/`**. An implementer coding the row literally gets a permanent red; the likely field repair is to drop the companion assertion, which is exactly the guard against "a script added later without a mode bit passes unlisted" that this round added. The root is §4.4's premise: `FIVE_SCRIPTS` (`bootstrap.test.js:55`–`:61`) never contained `check-req-size.sh`, so its "2 deleted / 3 surviving" partition is right about `FIVE_SCRIPTS` and wrong about the post-sweep shipped set — and §4.4 then attributes those three to "the three hooks AC-3.3 names", while AT-3.3 clause 2 in this same document names **four** surviving entries including `check-req-size.sh`.
