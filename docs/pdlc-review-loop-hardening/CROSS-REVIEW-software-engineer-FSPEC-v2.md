| F-10 | Medium | Local | **AT-19's `process` / `fetch` clause is still a bare-reference test and is still red on a correct artifact — v1 F-05's defect, narrowed but not closed.** The restated AT reads "no `import` **line**, no `export` past `meta`, and no reference to `process` or `fetch`". I ran the scan: `pdlc/workflows/dist/orchestrate-dev.bundle.js` contains `process` once and `fetch` twice, and the queue bundle likewise. The occurrences are the `BANNER` comment (`" * NO \`import\` (static or dynamic), no \`process\`, no \`fs\`, no \`fetch\`; the only"`) and a prompt literal in `rebaseOntoDefault`'s instructions (`` `1. Fetch the latest default branch from remote: git fetch origin <default-branch>.\n` ``). Both are healthy: one is the build's own banner, the other is agent-facing prose. The AT also claims to be "the existing test extended, not a second, stricter gate" — but `runtimeBundle.test.js` asserts **no** `process`/`fetch` condition at all (its structural assertions are `toMatch(/^export const meta = \{/)`, `match(/^export /gm)` length 1, and `not.toMatch(/^import\s/m)`), so the clause is in fact new *and* stricter *and* failing. Fix in the same direction as the `import` half: make the clause about an executable reference (identifier occurrences outside comments and string literals), or drop `process`/`fetch` from the substring gate and keep only the three conditions the existing test can actually assert. As written implementation will either weaken this arbitrarily or ship a red gate — the same outcome F-05 predicted. | §19 AT-19 |
| F-11 | Medium | Local | **The `APPROVAL-HASH:` scan was left whole-file while the verdict scan was narrowed, so a cross-review that quotes §7.4's grammar denies its own round's approval.** §6.2's new Scan-scope row narrows the verdict read to "the trailing `## Verdict` section only", explicitly because the whole-file rule "misclassifies any cross-review that *quotes* the grammar … so the mechanism defeated itself on the reviews of its own feature". The identical hazard on the anchor is untouched: §7.4 says "the script counts `APPROVAL-HASH:`-prefixed lines **in the file**", and §10.1's read side specifies no scope at all ("Each may carry an `APPROVAL-HASH:` line"). ## Positive Observations

- **Every High closed, and closed in the normative text rather than the changelog.** F-01 and F-02 were the two that had to close before TSPEC, and both are fixed by the method I would have chosen: F-01 by *deleting* the losing sentence and deferring to the single owning section, F-02 by a total unanimity table with no tie-break and matching §10.5 / §18.2 / AT rows.
- **The retraction-in-place discipline is the strongest thing about this revision.** §5.1, §5.3, §11.5, §16.3, §15.4's `faultObserved`, §3.5 and §1.4 all quote the withdrawn v1.0 sentence verbatim before replacing it, and §21.3's ledger is kept current. That is what makes a delta re-review cheap and is exactly the R-5 property this feature exists to install — the change surface, not the iteration count, is what bounded this pass.
- **F-06's fix is better than what I asked for.** I asked for an early-exit rule *or* a read budget; the author took the stronger option, retracted the descent entirely, and produced a cost with no history-length term at all — then found and closed a fail-open skip (E-65) I had not seen, in the same edit as TE F-01.
- **Every build fact in the F-04 fix is measured, not asserted.** I re-checked all four anchors in `build-runtime.mjs` at `0655387` (the queue `wrapModule`'s `exportedNames` array, the dev bundle's `contents` array, the `const realMain = __dev.main;` prelude, `DEV_ENTRY`'s `args && typeof args === "object" && args.reqPath` test) and `rewriteStatus`'s non-exported declaration in `orchestrate-queue.js`. All correct. The `_git`-on-`main()` threading gap I raised separately is also closed in §17.3's queue paragraph.
- **The SKILL edit that makes §6.2's new scan scope implementable is already in the change surface** — §17.5's `§Cross-Review File Format` row requires appending a final `## Verdict` section in §6.2's exact grammar. Narrowing the scan to a heading the template does not yet mandate would otherwise have been a false-halt regression; it is not, and E-08 covers the legacy population.
- No High findings remain. The three open Mediums are each a single clause, and two of them (F-10, F-12) are residues of fixes that were 80% landed rather than fresh design gaps.
