- **PROP-DET-01** (TZ independence) — confirmed via full read of `pdlc-drift.sh`/`check-workflow-drift.sh`/`sync-workflows.sh`: the only clock read anywhere is `date -u +%Y-%m-%dT%H:%M:%SZ` for `generatedAtUtc`, which (a) is UTC-fixed (`-u`) so `TZ` cannot affect its value, and (b) is excluded from every determinism comparison in this suite (`strip(generatedAtUtc)`). No classification rung reads `TZ`, the clock, or any timestamp (`pdlc-drift.sh:1351`'s own comment: "No mtime anywhere (R-2)"). No branch exists to invert. Residual.
- **PROP-DET-05** (locale independence) — **residual on Darwin only; mutation named and attempted.** Mutation: delete `export LC_ALL=C` / `export LANG=C` from `pdlc-drift.sh:28-29` and `check-workflow-drift.sh:22-23`, so the caller's `LC_ALL=en_US.UTF-8` reaches the scripts. Result: **stayed green**. Cause: the only locale-sensitive surface in the pipeline is the not-managed listing's sort, which uses bash-native `[[ a < b ]]` (`sort` is not on the probe PATH allow-list) — and macOS bash 3.2 compares bytes there regardless of collation (verified directly: `LC_ALL=en_US.UTF-8 /bin/bash -c '[[ "B.js" < "a.js" ]]'` is true, same as under `LC_ALL=C`). glibc's bash does collate, so the mutation is expected to go red on a Linux runner. The test fixture was **strengthened** as part of this adjudication to place two collation-ambiguous extras (`B.js`, `a.js`) in the tree and assert byte order in both runs' stdout, so the property is no longer vacuous and will falsify wherever `[[ < ]]` honours collation. Residual is therefore platform-scoped, not structural.
