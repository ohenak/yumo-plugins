## Positive Observations

- **§2.1's two-phase restructure is the right fix, not a patch.** Separating evidence gathering from reason selection makes §2.8's precedence the selector rather than a commentary on one, and the Phase-2 argument that an `indeterminate` condition is never selected holds over every dependency edge (E5/E6 behind E2, E4 behind E3). §2.8's worked table converts the precedence into fixtures an O-9 author can start from immediately. F-16 is a consequence of removing the short-circuit, not of the restructure itself.
- **§2.7 and §4.4's `checkEnabled` honesty note are exactly what F-05 asked for.** Naming the residual, naming the remediation, rejecting both escape hatches with reasons, and correcting the rung's stated purpose is better than inventing a `grep`-of-JSON path — and it removes an unfalsifiable oracle rather than dressing it up.
- **§4.4's escaping rule replaces a boundary definition with a class removal.** "Every byte printable ASCII, else `<unprintable>` wholesale" is decidable byte-wise under `LC_ALL=C`, needs no UTF-8 validator in a `printf`-only emitter, and states its cost. This is the shape a spec clause should take when the alternative is asking an implementer to detect invalid UTF-8 in bash.
- **§1.4's mandatory zero-padded `-NN` is a real derivation, not a convention.** The optional-suffix form genuinely made AC-3.4's sort clause false (`.` `0x2E` vs `-` `0x2D`), the fixed-24-byte tail makes `format` injective, and O-18 turns it into a property obligation with the stamp-shaped-id case named explicitly.
- **§8.2's `distinct(a,b)` predicate with substring exclusion in both directions** is the correct oracle: it defeats the naive "reach inequality by appending the id" implementation that plain `!=` would have passed, and S1/S2/S3 make the pairwise scope explicit.
- **§6.1 states the LLM-mediated `_readFile` seam plainly and routes it as O-19** rather than asserting NFR-1 covers it. Separating "the decision has no model in it" from "the transport does" is exactly right, the corruption-vs-defence table is falsifiable, and O-19(b)'s mangled-relay fixture list (fenced, re-wrapped, truncated, key-dropped, scalar-swapped, value-reworded) is a directly implementable test inventory. The green direction is already covered by AT-5/AT-7/AT-9/AT-24, so the validator cannot false-green by rejecting everything.
- **§6.2's D1–D8 plus the terminal row 10** make the mapping total by construction and fail-closed, and D5-before-row-2 closes the "opt out via a missing field" hole.
- **AT-27 and AT-26** are both well-formed: three positive conjuncts each, and each is red against a specifically named wrong implementation rather than against nothing.
