## Positive Observations

- **AC-1.0 is the structurally right answer to the false-green class, and it is applied at all three seams consistently.** Making baseline resolution a manifest-level precondition with its own closed reason set — then guarding hook silence (AC-2.2), `--check` exit `0` (AC-3.3 row 5) and queue proceed-silently (AC-4.1 last row) on `resolved` **and** a non-empty row set — eliminates the vacuous-universal-quantification hole by construction rather than by test. Including `manifest-empty` as an `unresolved` reason, with the rationale stated inline ("a managed set of size zero can satisfy any universally quantified claim without verifying anything"), is the part most specs get wrong. AC-2.5a exists precisely because every other warning is row-quantified and would have nothing to quantify over — that is the correct derivation, not an afterthought.
- **The AC-6.4 oracle is now a real expression rather than a list, and I could execute it.** `coveredViolations(root) := grep(root, PATTERNS) − { p : exempt(p) }` with four literal ERE alternatives is the first version of this AC that a reader can run. I ran it: 25 hits, exemption rule applied mechanically, five covered violations, and every one of the five `file:line` citations is exact — `docs/_queue/QUEUE.md:41-42`, `docs/design/MASTER-PLAN-engineering-loop.md:82-83`, `docs/PLAN-pdlc-integration-boundary-gates.md:134,184`, `pdlc/workflows/orchestrate-dev.js:5`, `pdlc/workflows/orchestrate-queue.js:5`. Noting that patterns 3 and 4 are the *only* way the two most live normative surfaces enter the set is the observation that explains why every earlier revision undercounted. F-01 is a hole in the exemption rule, not in the design.
- **AC-0.7's `retires` array is the right fix and it is justified from the failure it prevents.** Naming why a flat list cannot work (no key back to a row; basename matching is an unauthorised inference that breaks on the third artifact) and then writing the falsifying test inline — *`R.pluginPath` absent ⇒ R `unknown` ⇒ sync runs ⇒ `R.retires` paths still exist and `retire-skipped` was reported* — converts an unfalsifiable guard into a per-row relation a fixture can state. AC-0.1's two well-formedness rules (no path in two rows' `retires`; no `retires` member equal to any `consumerPath`) close the aliasing hole in the same breath.
- **AC-6.5 is the correct shape for a bootstrap AC**: two literal commands, an explicit "no published release, no installed plugin, no network", and the postcondition stated at all three surfaces. I verified it is actually achievable — `pdlc/workflows/dist/` is tracked, so `build` is a no-op on a fresh clone and `sync` has a manifest to read.
- **AC-6.2(b)'s de-tautologising is a subtle catch, correctly generalised.** Replacing "byte-identical to the freshly built bundle" with "recompute `sha1` from the bytes on disk" *and* adding "no test in this feature runs the builder in a way that writes into `pdlc/workflows/dist/` — the suite never mutates its own tracked inputs" states the invariant, not just the fix.

## Recommendation

**Needs revision**

Must change before FSPEC:

1. **F-01 — the blocking one.** AC-6.4's exemption rule must cover test fixtures, or its two mandatory assertions cannot both be satisfied in one `npm test` run and the implementer will drop the real-root binding. Add `**/__tests__/**` (or `pdlc/workflows/__tests__/fixtures/**`) as a fourth exemption rule with its rationale.
2. **F-02** — AC-0.5 must derive the root from the main worktree's *work tree*, not from the parent of its git directory, and §4 must declare the minimum git version with the degradation path when it is absent. As written, a submodule or `--separate-git-dir` consumer resolves to a readable non-root that passes every declared guard, and AC-3.8 then creates `.claude/workflows/` inside the git directory.
3. **F-03** — give a present-but-unreadable `consumerPath` a state and a reason. AC-1.2's set is closed, AC-1.8(i) demands totality, and the only currently-reachable answer (`missing`) is the one sync overwrites without a backup.
4. **F-04–F-07** — de-label §0 fact 14's listing as verbatim (or paste the real output), restate AC-3.4's regex in POSIX ERE, retarget AC-0.1/AC-0.2's `manifest-malformed` citation to AC-1.0, and point D-DIST-07 at the queue row rather than a nonexistent REQ.
