## Positive Observations

- **PL-01's resolution is product-sound and correctly flagged rather than silently taken.** Gitignoring `pdlc/workflows/dist/` would make AC-6.1's "tracked and committed" sole build output uncommittable without `git add -f` and would break AC-6.2a's installed-package assertion and AC-6.6's working-tree observation point. Writing only the anchored `/.claude/workflows/` entry, honouring §10.1's *anchoring* rule as a conditional, and verifying with `git check-ignore -v` that neither the real `dist/` nor the fixture's nested `pdlc/workflows/dist/` is swallowed is the right call. The anchoring rationale (an unanchored pattern turns AT-23's `== 7` into `== 0` with no explaining diff) is exactly the kind of silent-false-green the REQ was iterated to prevent.
- **The three sibling hook scripts are not lost.** REQ §6 deliberately pulled the latent exit-126 class into scope; L-03 names all five scripts, §4.1 gives the three siblings a mode-only owner row, and §9 states both objects (index `100755` **and** on-disk `X_OK`) plus `100644` for the sourced library. This is the bullet most likely to be quietly dropped, and it is not.
- **L-04 is sequenced after L-03 for the right product reason** — "registering a `100644` script is the exact exit-126 class this feature exists to close" — which is the one ordering constraint in Phase 7 that is genuinely about user outcome rather than file collision.
- **AT-24 exercises the whole user journey end to end** (fresh clone → build → sync → `--check` exit 0 → `mapDriftState` row 9 → nothing written under `$HOME`), including the `syncCommand` string-equal expansion. US-02's "single command" promise has a real oracle, not a description.
- **§7's obligation table gives every upstream hand-off a landed owner**, and R-12 is explicitly routed rather than left as a bare deferral — that is the DoD failure mode this table pre-empts.
- **§9's "zero unexpected skips" framing** (every skip must be a TSPEC §1.3 / PROPERTIES §11.1 inventory row with a named unverified invariant) keeps the coverage floors from being satisfiable by silence.
