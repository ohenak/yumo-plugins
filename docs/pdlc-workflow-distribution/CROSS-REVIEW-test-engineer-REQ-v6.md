| F-01 | High | Local | **AC-6.4's mandated RED case has nowhere to live: the discovery rule and the exhaustive exemption set make it either unimplementable or self-defeating, so the shipped test can only pass.** The AC requires (i) `coveredViolations(repoRoot) == ∅` and (ii) "RED and GREEN both run against `__tests__/fixtures/` trees", with file discovery "`git ls-files` when `root` is a git work tree and a directory walk otherwise". `pdlc/workflows/__tests__/fixtures/` is inside this repo's work tree, so discovery there is `git ls-files` — tracked files only — and the exemption rules (generated trees; `docs/<dir>/` containing a `REQ-*.md`; manifest `retired`/`retires` values) do **not** cover `pdlc/workflows/__tests__/**`. The implementer therefore faces two doors and both are closed: **(a)** commit the RED fixture — it is then a tracked file at a *covered* path stating the superseded convention, so assertion (i) is permanently red, and the exemption set is declared "normative and exhaustive" so it cannot be exempted without changing this AC; **(b)** write the fixture at test time — it is untracked, `git ls-files` does not return it, `coveredViolations` returns `∅`, and the "RED" case is green. Door (b) is the one an implementer takes (it keeps the suite green), and it produces precisely the assertion-that-cannot-fail this AC was written to prevent — the same degradation TE v4 F-04 and v5 F-06 named, now one level down. Fix mechanically: require the fixture root to be a **non-git temp tree** (the house pattern already exists — `pdlc/workflows/__tests__/fixtures/tmpGitFixture.js` builds its fixtures under `os.tmpdir()`), so the directory-walk branch is the one exercised and no fixture is ever tracked; state that the fixture root is created and removed by the test and is never inside the repo work tree; and, if in-repo fixtures are kept instead, add `**/__tests__/fixtures/**` to the exemption table as a fourth rule and require the RED fixture to be **committed** so it is discoverable. Either is fine — but the REQ must pick one, because as written the only implementation that is green on both assertions is the one that proves nothing. | AC-6.4 "checker is a pure function of a root directory" / "Falsifying case"; exemption table; §6 |
