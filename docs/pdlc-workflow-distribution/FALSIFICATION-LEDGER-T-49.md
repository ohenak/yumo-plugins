### Adjudication (orchestrator)

Both defects T-49 reported are in **test helpers**, not production, and are confirmed. Neither is fixed here:

1. **`helpers/bin/lib-probe.sh:57-58` exports `LC_ALL=C` / `LANG=C`**, so a caller-injected locale never reaches
   C1 through `runProbe` — making TSPEC §11.3 row 2's injection and T-30's existing locale test at
   `driftBackups.test.js:113` vacuous. Confirmed empirically by T-49 (deleting C1's own exports leaves that test
   green). **Not fixed:** removing the harness exports would restore the injection path but cannot make
   PROP-BKP-07 green, because the property holds by construction independently — within one id C1 only ever
   compares fixed-layout names that differ in digit positions, which no collation reorders. The change would
   therefore buy no falsifiability while perturbing every probe-routed suite. The vacuity is recorded here and
   carried to Phase CR. Same class of defect as T-47's `buildNonGitClaudeAtHome` sibling-tmpdir vacuity.
2. **`helpers/bin/backup-grammar.sh` reads cases with `while IFS=$'\t' read -r kind a b c`**, which collapses
   consecutive tabs — a case with an empty field silently mis-parses into the wrong columns instead of erroring.
   T-49 worked around it by routing the empty-id case through `runProbe`. **Not fixed:** latent, no current case
   hits it, and the fix belongs with the helper's owner. Carried to Phase CR.
