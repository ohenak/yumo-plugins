## Positive Observations

- AC-0.3a's restatement as a single variable binding (`<pluginRoot> := <repoRoot>/pdlc`, everything joins unchanged) is the right shape: one substitution, no second composition rule, and the failed v4 phrasing is recorded so it cannot be re-derived. The maintainer green path is now genuinely reachable, which is what makes AC-3.3 exit 0 and AC-2.2 silence testable at all.
- Routing `retiredPresent` as a top-level field rather than forcing it into `rows` preserves AC-2.6's one-entry-per-manifest-row invariant *and* AC-1.8's codomain, and keeps the queue at one injected read. That is three constraints satisfied by one schema decision, with the reasoning recorded in AC-4.1.
- AC-2.8 closes the v4 F-03 hole properly: a named token, textual distinctness from all four other warning classes, per-path naming, and an explicit statement of the silent-`else` implementation it exists to exclude.
- AC-3.7's version-control caveat — "a test that asserts AC-3.7 while `git ls-files` still returns the retired paths is asserting a property of the git index, not of sync" — is precisely the kind of anti-false-green instruction a REQ should carry, and it names the landing step that makes the fixture independent.
- AC-6.2's "build inputs in the package are tolerated, not asserted away", with the reason (the converse would go red on the current tree and encode a hygiene requirement this REQ does not make), is the correct way to decline a plausible-sounding assertion.
- AC-6.4's insistence on a two-directional falsifying case is the right instinct even though the seam is missing (F-06) — it names the exact degradation ("the implementer facing a red grep will narrow the pattern until it passes").
- §10's finding-by-finding disposition made this the cheapest re-review of the five: every claim of resolution pointed at an AC I could check in one jump.

## Recommendation

**Needs revision**

Blocking changes before FSPEC:

1. **F-01** — make manifest/baseline resolution a precondition evaluated before every row quantifier, so an empty managed set can never produce hook silence, exit 0, or a proceeding queue. This is the flagship false green and it is currently reachable on the state every consumer is in at rollout.
2. **F-02** — give the retirement guard computable data (a per-row `retires` field) or restate it as a whole-run precondition; as written the only delete path in the feature has an unfalsifiable safety condition.
3. **F-03** — state AC-6.4's patterns as literal, qualifier-free regexes and paste the real output of the exact command; §0 fact 14's classification does not match what the cited grep returns, and the two most live normative surfaces are outside it.
4. **F-04** — state that retirement is manifest-derived and not evaluated when the manifest is unresolved; fix AC-2.8's Who; give `retiredPresent` a specified value in AC-0.3b.
5. **F-05** — make the covered/exempt sets provably partition the tree by expressing one of them as a rule.
6. **F-06** — give the AC-6.4 checker a root-directory seam so the mandated RED case runs against a fixture tree.
7. **F-07** — resolve whether AC-6.2(b) rebuilds or is discharged by AC-6.3; the default implementation is a self-comparison.

Low findings F-08–F-10 fold into the same revision but do not independently gate.
