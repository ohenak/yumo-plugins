| F-01 | Medium | Local | **The 44-test cost is overstated by 69%; measured, it is 26.** O-1 and DEC-WVR-01 both reject the `WaveResumeStore` rewrite on "it invalidates the 44 shipped tests that reach them — 32 in the ledger `describe`, 8 in the `implementation.startWave` block, 4 in `computePlanHash`". Running that suite at `origin/main` (`npm test -- __tests__/waveExecution.test.js --verbose` from `pdlc/workflows`) gives **18** in `describe("Phase I — the INTERIM wave ledger resumes a halted run unattended")` (14 `it` blocks, one of which is the four-member `it.each`), **4** in `describe("Phase I — implementation.startWave resumes a halted run")`, and **4** in `describe("computePlanHash — the ledger's plan fingerprint")` — **26**, not 44, and no other test file at `origin/main` references `WAVE_STATE_PATH`, `computePlanHash`, `parseWaveLedger` or `formatWaveLedger`. The decision does not flip on this — 26 tests is still a large regression net, and O-1's other two grounds (the `.gitignore` anchor and the no-`import` dialect) are independently verified and stand on their own. But this document's stated standard is a counted cost with the command that produced it, and this is the one cost claimed without one. *Fix:* replace `44 / 32 / 8 / 4` with `26 / 18 / 4 / 4` in O-1 and DEC-WVR-01, and cite the command (`npm test -- __tests__/waveExecution.test.js --verbose`, run from `pdlc/workflows` at `origin/main` `345ae358`) beside it, as the surrounding rows already do. | REQ BL-03, R-4 |
