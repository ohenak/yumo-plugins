| F-12 | Medium | Local | **The unconfirmable answering-line write is a fourth dispatch-less entry class, and it is routed onto a refusal path whose three operator-visible renders all take an argument it cannot supply.** The new clause says: *"the entry **refuses the phase** on step 4's path, and the failure is reported through the channel O-5 names … It mints **no new catalogue id and no new S-16 reason** (that enum is closed at three)."* Step 4's path is fully specified — but every one of its operator-facing artifacts is keyed to an S-16 reason that does not exist here, because the region **passed** steps 1–3 (that is why a grant was attempted): (a) the ❌ phase row is declared in §6 as `Refused — reset region corrupt at {path} ({reason})` — the region is not corrupt and `{reason}` is unbound; (b) the recovery text is declared as *"names the sanctioned repair for `{reason}`"* — the repair table has no row for an IO fault, and the sanctioned action here is *re-run*, not an edit; (c) **row B** is defined as `notice` = **S-16 alone**, so the row renders with every cell empty or unbound.
