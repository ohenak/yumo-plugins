| F-01 | High | Local | **AC-1.4's new *no re-author* criterion falsifies AC-1.3 on exactly the case AC-1.3 was written for, and O-14 resolves the collision by licensing FSPEC to amend the REQ.** AC-1.3 is quantified *"When: the loop halts on the budget"* and requires the Iterations section to state the rounds this entry ran, *"`0` there"*, because *"AC-1.5(1) makes a **zero-round** halt the commonest new case"*. AC-1.4's new clause then says a halt finding an existing post-mortem *"changes nothing else in the file — no authoring dispatch, every other section including `## Recommendation` byte-unchanged"*. The Iterations section **is** one of those other sections. So on the zero-round halt the Iterations section is only ever written when the post-mortem does **not** already exist — and the zero-round halt is by construction a re-entry into an exhausted window, which in the ordinary path follows the halt that created the post-mortem. The operator therefore reads the *previous* halt's `rounds run {k}` (typically 1) on precisely the entry AC-1.3 promises will read `0`. Only the R-13 migration branch (3+ rounds on disk, no post-mortem yet) reaches the creating-halt path with zero rounds, so the promise holds on the rare case and fails on the common one. **O-14 does not close this; it records it and delegates:** *"which fixes that file's Iterations section as left as the prior halt wrote it **unless FSPEC states otherwise and amends the clause**"*. An `O-*` obligation cannot authorise the downstream document to amend an acceptance criterion — that inverts the altitude relation §10 and DC-09 rest on, and it leaves an **operator-visible** outcome (which number the operator reads after a re-halt) undecided at requirements altitude, which is not the kind of thing DC-09 permits deferring. This is a product decision with three defensible answers (the region-maintenance write also rewrites the Iterations line; the section carries a per-halt list; AC-1.3 is scoped to the creating halt and the re-halt is stated to be silent). Pick one in the REQ. | AC-1.3, AC-1.4 (*"does not re-author"*), O-14, §2 (*Operator-visible surfaces*) |
