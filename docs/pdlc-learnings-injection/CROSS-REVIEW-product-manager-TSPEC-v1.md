## Positive Observations

- **Byte-identity made structural rather than tested.** §A.2 property 3 and §I.4's `null` injector mean a disabled run, an empty corpus and an admits-nothing configuration produce the pre-feature string by construction, and the disabled path is a branch never entered. AC-5.1a and AC-4.1 are honoured in the design instead of being left to a test to discover.
- **Self-exclusion decided before any read** (§D.6), by feature directory rather than filename, closes AC-1.3 and E-31 in one rule and keeps the existing Tier-2 LEARNINGS reader undisturbed.
