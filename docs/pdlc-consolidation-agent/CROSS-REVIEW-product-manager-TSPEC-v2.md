That is DC-07's "production path ≠ unit path" caught **before** implementation rather than at DoD, which is the best possible place to catch it.
- **§12.3 replaced range notation with an exhaustive enumeration, and the enumeration is exactly right.** I extracted the FSPEC's AT register (96 distinct ids) and §12.3's own rows (96 distinct ids) and diffed the two sets in both directions: empty, both ways. The three ids the ranges silently dropped — AT-C1b, AT-Q7b, AT-Q7c — are now assigned.
